Point-Blank Executions
---
<img width="800" height="450" alt="ezgif-710cc6514544e45b" src="https://github.com/user-attachments/assets/a8a2ce45-4199-4dbb-b29a-b4b0d2acb63c" />

- A simple (and somewhat "wacky") `GTA:SA` mod that allows you to do "point-blank executions" like in the `RDR` Games.
- All delays and animations are configurable via `config.ini` and hot-reload is supported with the cheat that is also found in `config.ini.`
- Error handling is not implemented for `config.ini` and therefore the game will most probably crash if you have a bad config!
